# MaxMoll

Полнофункциональная система управления складом, заказами, поставками и перемещениями товаров с учетной системой (Ledger / Stock Movements) и встроенным SPA-интерфейсом на Vue 3.

---

## 🚀 Основные возможности

* **Управление клиентами:** Создание, просмотр и редактирование данных клиентов (`customers`).
* **Управление складами и остатками:** Мониторинг товаров и их количества на складах (`stocks`).
* **Заказы:** Оформление заказов со списком позиций, списание остатков при проведении (`completed`), возможность отмены (`canceled`) и редактирования состава.
* **Поставки и Перемещения:** Проведение поставок (`supplies`) для зачисления товаров и межскладские перемещения (`transfers`) с проверкой наличия.
* **История движений (Stock Movement Log / Ledger):** Прозрачный аудит любого изменения количества товаров со связью через полиморфный документ-источник (`doc_type` + `doc_id`).
* **Интерактивный UI на Vue 3:** SPA-интерфейс для работы с заказами и просмотра истории движений.
* **Автоматическая API Документация:** Встроенная интерактивная OpenAPI 3.0 (Swagger) документация.
* **Моковые данные (Seeders):** Готовые скрипты сидирования для быстрого разворачивания тестового окружения.

---

## 🛠 Технологический стек

* **Backend:** PHP 8.2+, Laravel 10+, MySQL
* **Frontend:** Vue 3 (Composition API), Vite, Bootstrap 5, Axios
* **API Doc:** Scramble (OpenAPI 3.0 / Stoplight Elements)

---

## 📚 Документация API (Scramble)

В проект интегрирован пакет **Scramble**, который автоматически генерирует актуальную спецификацию OpenAPI на основе типа возвращаемых данных, `FormRequest`-валидаторов и `Resource`-классов.

После запуска проекта документация доступна по адресу:
👉 `/docs/api` (или ваш локальный домен/хост)
---

## 🗄 Моковые данные (Seeding)

Для быстрого тестирования в проекте созданы сидеры, заполняющие базу тестовыми клиентами, складами, товарами, начальными остатками, поставками и историями движений.

### Установка зависимостей PHP
```bash
composer install
```

### Установка зависимостей JS
```bash
npm install
```

### Запуск сидирования:
```bash
php artisan migrate:fresh --seed

```
